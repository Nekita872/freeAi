# freeAi

**freeAi** — Android-приложение для работы с подключением к AI-сервисам с использованием локального VPN и управления IP-адресами и DNS для выбранных доменов.

Приложение создано для удобного управления подключением к популярным нейросетям, включая ChatGPT, Grok, Gemini, Claude и другие AI-сервисы.

## Возможности

- **Локальный VPN** — сетевой механизм приложения для обработки выбранного трафика.
- **IP / DNS** — управление параметрами подключения к AI-доменам.
- **Авто-подбор** — функция подбора IP / DNS, доступная в приложении.
- **Выбор сервисов** — возможность выбрать необходимые AI-сервисы.
- **Удобное управление** — включение и выключение подключения из приложения.

## Как пользоваться

1. Скачай и установи APK-файл freeAi.
2. Открой приложение.
3. Перейди в раздел **IP / DNS** и запусти авто-подбор.
4. В разделе **Сервисы** выбери нужные AI-сервисы.
5. Вернись на главную страницу и нажми **Включить**.
6. Разреши создание VPN-подключения, если Android запросит разрешение.
7. После использования нажми **Выключить**.

## Важно

- Работа приложения зависит от доступности IP-адресов, DNS и самих AI-сервисов.
- Подбор IP не гарантирует доступность сервиса.
- Приложение не гарантирует обход всех региональных ограничений.
- Для работы отдельных функций может потребоваться дополнительная настройка.
- Локальный VPN сам по себе не означает, что весь интернет-трафик проходит через удалённый VPN-сервер.
